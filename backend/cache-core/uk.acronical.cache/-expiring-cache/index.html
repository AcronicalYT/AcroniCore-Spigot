ExpiringCache

open class ExpiringCache<K, V>

A thread-safe, time-based cache for storing temporary data.

Utilises Google Guava to provide automatic expiration and size-based eviction, protecting the framework from memory leaks whilst caching expensive operations (e.g., database queries or UUID lookups).
